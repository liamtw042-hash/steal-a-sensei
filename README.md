# Steal a Sensei

Roblox tycoon: run into zones, grab scrolls, outrun the zone boss back to your base, hatch fighters, earn cash, raid other bases. Original anime style.

Built with **Rojo** (file sync), **Wally** (packages), **Knit** (framework) and strict **Luau**.
